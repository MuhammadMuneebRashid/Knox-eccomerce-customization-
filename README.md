# KNOX Official - Luxury E-Commerce Store

Welcome to the official GitHub repository for **KNOX Official**, a modern, high-end e-commerce web application specializing in aerospace-grade metal pop-up card wallets and luxury Extrait de Parfums (including KNOX Legacy and KNOX Royale).

## 🚀 Project Overview
This project focuses on building a streamlined, conversion-optimized shopping experience using WordPress, WooCommerce, and Elementor. The goal is to minimize friction during the checkout process and provide alternative conversion paths like direct chat ordering.

## 🛠️ Tech Stack & Tools
* **Platform:** WordPress, WooCommerce
* **Page Builder:** Elementor
* **Backend Customization:** PHP
* **Hosting & Environment:** Spaceship, Custom Domain setup (`knoxoffical.com`)
* **Tracking & Analytics:** Google Tag Manager, Meta Pixel

## ✨ Key Features & Customizations
1. **Optimized Checkout Form:** Removed non-essential fields (such as Postcode, State, and Apartment number) tailored for regional user experiences, while resolving WooCommerce core validation conflicts.
2. **Direct WhatsApp Ordering:** Integrated a direct chat-to-order button (`Order via WhatsApp`) right inside the checkout funnel to boost conversion rates and reduce cart abandonment.
3. **Luxury UI/UX Design:** Dark-themed aesthetic matching the luxury branding of metal wallets and perfumes.
